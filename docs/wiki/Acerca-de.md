# Acerca de

## Descripción del proyecto
**Calculadora de IMC** es una aplicación web que permite a una persona registrarse, calcular su Índice de Masa Corporal (IMC) y dar seguimiento a la evolución de ese valor a lo largo del tiempo.

El IMC se obtiene con la fórmula **IMC = peso (kg) / estatura (m)²** y se clasifica según la Organización Mundial de la Salud en: bajo peso, normal, sobrepeso y obesidad.

## Objetivo
Aplicar los conocimientos de Jakarta EE para aplicaciones web, el patrón Modelo-Vista-Controlador (MVC) y los servicios web RESTful, construyendo una aplicación funcional con persistencia en base de datos.
